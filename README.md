# The Unknown Citizen — Version 33

This release adds an actual original instrumental soundtrack, Municipal Nocturne (53-second loop), and changes the game shift to 15 minutes.

For GitHub Pages, upload **index.html** and **municipal_nocturne.mp3** together at the root of the repository.

Alternatively, open **standalone.html**: it contains the music embedded in the same HTML file and needs no separate assets.

Click the MUSIC OFF button to start playback. Most browsers prohibit autoplay until a user clicks. Toggle again to stop.

All investigation, journal, score and “Did you notice?” mechanics are preserved. A new save key starts a new 15-minute game.
